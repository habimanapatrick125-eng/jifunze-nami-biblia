### 🚀 Jinsi ya Kufungua Mradi (Installation)
1. Download au clone folda yote ya `bible`
2. Hakikisha una faili zote 9 ndani ya folda moja
3. Double-clique kwenye `index.html`
4. Mradi utafunguka kwenye browser yako (Chrome, Firefox)
5. Usitafute jina kwenye Google, fungua kama faili local

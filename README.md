
# 📖 JIFUNZE NAMI BIBLIA

### Mradi wa Kujifunza Biblia kwa Kiswahili

**JIFUNZE NAMI BIBLIA** ni tovuti ya elimu ya Biblia inayolenga kuwasaidia watu kujifunza Maandiko Matakatifu, kuelewa mafundisho ya Biblia, kujifunza kutoka kwa watu wenye imani, na kutumia kanuni za Biblia katika maisha ya kila siku.

Mradi huu umetengenezwa kwa kutumia HTML5, CSS3 na Bootstrap 5.

## 🎯 Malengo ya Mradi

Malengo ya mradi huu ni:

1. Kusaidia watu kujifunza Biblia kwa Kiswahili.
2. Kueleza mafundisho muhimu ya Agano la Kale na Agano Jipya.
3. Kujifunza kutoka kwa mifano ya imani inayopatikana katika Biblia.
4. Kuelewa maonyo na mafunzo ya Biblia.
5. Kujifunza kuhusu maisha na mafundisho ya Yesu Kristo.
6. Kusaidia watu kutumia kanuni za Biblia katika maisha ya kila siku.
7. Kutoa njia ya kuwasiliana na mwandishi wa mradi.

## 🚀 Jinsi ya Kutumia Mradi

1. Pakua au clone repository ya mradi.
2. Fungua folda ya mradi kwenye Visual Studio Code.
3. Fungua faili `index.html` kwenye kivinjari.
4. Tumia menyu ya tovuti kutembelea kurasa mbalimbali.
5. Hakikisha una muunganisho wa intaneti ili kutumia Bootstrap CDN, ramani na picha za nje zinazohitaji intaneti.

---

## 🌐 Kuchapisha kwa GitHub Pages

Ili kuchapisha tovuti:

1. Pakia faili zote kwenye repository yako ya GitHub.
2. Fungua repository hiyo.
3. Nenda kwenye **Settings**.
4. Chagua **Pages**.
5. Chini ya Build and deployment, chagua **Deploy from a branch**.
6. Chagua branch `main` na folda `/ (root)`.
7. Bonyeza **Save**.
8. Subiri GitHub Pages ichapishe tovuti yako.

Baada ya kuchapishwa, utaweza kushiriki kiungo cha tovuti yako na watu wengine.
